# Issues — storygroove-be

Use GitHub Issues or your tracker of choice. This folder holds **templates** and lightweight **log files** for recurring triage.

## Contents

- [templates/](templates/) — copy into new issues
- [known-issues.md](known-issues.md) — active caveats affecting operators or developers
- [resolved-issues.md](resolved-issues.md) — recently closed themes (optional, high signal only)
- [triage-process.md](triage-process.md) — how we label and route work

## Scope

Log **service-level** bugs (API regressions, webhook failures, memory pipeline defects). Pure frontend bugs belong in the frontend repository unless the contract is wrong here.
